# Giri - Project Shop Food (UMKM Website)

A responsive and interactive front-end web landing page designed for a local food business (UMKM). This project showcases core web development skills in handling structured layouts and dynamic user interactions.

## 🚀 Live Demo
Check out the live website here: [https://github.io](https://github.io)
*(Catatan: Pastikan Anda sudah mengaktifkan GitHub Pages di menu Settings agar link ini aktif)*

## 🛠️ Technologies Used
*   **HTML5:** For semantic web structure and forms.
*   **CSS3:** For responsive design, typography, and button styling.
*   **JavaScript (ES6):** For DOM manipulation, action button events, and user input validation.

## 📌 Features
*   Clean and modern landing page interface for food product display.
*   Interactive buttons with hover effects.
*   User input forms equipped with fundamental data validation.
*   Fully responsive layout across mobile and desktop devices.
